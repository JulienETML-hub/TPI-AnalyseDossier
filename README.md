# TPI-AnalyseDossier
Application c# permettant d'analyser, répertorier et d'exploiter les informations liées à un emplacement de stockage local ou réseau
## 📦 Installation / Déploiement

### 🔹 1. Exécutable autonome (.exe)

1. Télécharger le fichier **`TPI_AnalyseDossier.exe`** depuis la release GitHub :  
   https://github.com/JulienETML-hub/TPI-AnalyseDossier/releases/tag/V1.0.0

2. Double-cliquer sur le fichier téléchargé

3. Lors du premier lancement, une fenêtre Windows peut apparaître :  
   **"Windows a protégé votre ordinateur"**

4. Cliquer sur :
   - **Informations complémentaires**
   - puis **Exécuter quand même**

5. L’application se lance normalement  
   👉 Cette étape n’est nécessaire qu’au premier lancement

---

### 🔹 2. Installation via ClickOnce

1. Télécharger le fichier **`Installeur.zip`** depuis la release GitHub :  
   https://github.com/JulienETML-hub/TPI-AnalyseDossier/releases/tag/V1.0.0

2. Extraire le fichier `.zip` dans un dossier de votre choix

3. Ouvrir le dossier extrait

4. Double-cliquer sur **`setup.exe`**

5. Si un avertissement Windows apparaît :  
   **"Windows a protégé votre ordinateur"**

6. Cliquer sur :
   - **Informations complémentaires**
   - puis **Exécuter quand même**

7. L’application s’installe automatiquement :
   - un raccourci est créé
   - l’application est accessible via la recherche Windows (**TPI_AnalyseDossier**)

---

## ⚠️ Remarque de sécurité

L’avertissement Windows SmartScreen apparaît car l’application n’est pas signée numériquement.  
Cela ne signifie pas qu’elle est dangereuse, mais simplement qu’elle n’est pas encore reconnue par Microsoft.

---

## ✅ Prérequis

- Système d’exploitation : Windows 10 / 11
- Aucun besoin d’installer .NET (version autonome incluse)
- 2 Go RAM Minimum (4 Go Recommandé)
- SSD fortement recommandé (Utilisation avec HDD possible, mais lenteur possible selon l'envergue du scan)
